# Tarot Card Reading Tracker

A mobile application called "Drawn" for tracking and organizing tarot card readings with intuitive spread selection and card assignment capabilities.

## Features

- **Reading Management**: Create, view, update, and delete tarot card readings complete with notes and attachments
- **Spread Selection**: Choose from various tarot spreads (3-card, Celtic Cross, etc.) during reading creation
- **Card Assignment**: Assign cards to specific positions within selected spreads
- **Card Management**: Add custom/oracle cards in addition to standard Rider-Waite-Smith imagery
- **Reading History**: View chronological history of all readings with date, cards, and notes
- **Local Storage**: All readings stored locally on your device
- **Intuitive UI**: Clean, modern interface
- **True CI/CD**: Automatically publish and deploy to F-Droid using Github CI/CD functionality
