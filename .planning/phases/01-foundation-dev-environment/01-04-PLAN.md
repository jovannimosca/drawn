  <name>Task 1: Create Hilt DI modules for database and repositories</name>
  <files>app/src/main/kotlin/com/example/drawn/di/DatabaseModule.kt, app/src/main/kotlin/com/example/drawn/di/RepositoryModule.kt</files>
  <action>
    1. **DatabaseModule.kt** — Provides AppDatabase and all DAOs:
       ```kotlin
       @Module
       @InstallIn(SingletonComponent::class)
       object DatabaseModule {
           @Provides
           @Singleton
           fun provideDatabase(@ApplicationContext context: Context): AppDatabase =
               Room.databaseBuilder(context, AppDatabase::class.java, "drawn_database")
                   .createFromAsset("database/drawn_prepopulated.db")
                   .setJournalMode(RoomDatabase.JournalMode.WRITE_AHEAD_LOGGING)
                   .build()

           @Provides fun provideDeckDao(db: AppDatabase): DeckDao = db.deckDao()
           @Provides fun provideCardDao(db: AppDatabase): CardDao = db.cardDao()
           @Provides fun provideSpreadDao(db: AppDatabase): SpreadDao = db.spreadDao()
           @Provides fun provideReadingDao(db: AppDatabase): ReadingDao = db.readingDao()
           @Provides fun provideReadingCardDao(db: AppDatabase): ReadingCardDao = db.readingCardDao()
           @Provides fun provideReadingPhotoDao(db: AppDatabase): ReadingPhotoDao = db.readingPhotoDao()
       }
       ```

    2. **RepositoryModule.kt** — Provides all repository implementations:
       ```kotlin
       @Module
       @InstallIn(SingletonComponent::class)
       object RepositoryModule {
           @Provides fun provideCardRepository(cardDao: CardDao, deckDao: DeckDao): CardRepository =
               CardRepository(cardDao, deckDao)
           @Provides fun provideReadingRepository(readingDao: ReadingDao, readingCardDao: ReadingCardDao, readingPhotoDao: ReadingPhotoDao): ReadingRepository =
               ReadingRepository(readingDao, readingCardDao, readingPhotoDao)
           @Provides fun provideSpreadRepository(spreadDao: SpreadDao): SpreadRepository =
               SpreadRepository(spreadDao)
           @Provides fun provideDeckRepository(deckDao: DeckDao): DeckRepository =
               DeckRepository(deckDao)
       }
       ```

    3. **Scoped providers**: All DAOs are singleton-scoped (inherited from DatabaseModule's singleton). Repositories are also singleton-scoped since they hold no mutable state — they're pure function wrappers around DAOs.
  </action>

  <action>
    Create repository implementations that map between entities and domain models. Per ARCHITECTURE.md Pattern 1, repositories are the single source of truth.

    1. **CardRepository**: Accepts CardDao and DeckDao.
       - `fun observeAllCards(): Flow<List<Card>>` — delegates to cardDao, maps entities to domain
       - `fun observeCardById(id: Long): Flow<Card?>` — single card lookup
       - `fun observeCardsByDeck(deckId: Long): Flow<List<Card>>` — filter by deck
       - `suspend fun insertAllCards(cards: List<Card>): Unit` — bulk insert for pre-population

    2. **ReadingRepository**: Accepts ReadingDao, ReadingCardDao, ReadingPhotoDao.
       - `fun observeAllReadings(): Flow<List<Reading>>` — ordered by createdAt DESC
       - `fun observeReadingWithDetails(id: Long): Flow<ReadingDetail?>` — combines reading + cards + photos (use Kotlin `combine` or `zip` on multiple Flows)
       - `suspend fun createReading(reading: Reading, cards: List<ReadingCard>): Long` — transactional: insert reading, then insert reading cards
       - `suspend fun updateReading(reading: Reading, cards: List<ReadingCard>): Unit` — transactional: update reading, delete old cards, insert new cards
       - `suspend fun deleteReading(id: Long): Unit` — deletes reading (CASCADE removes reading_cards and reading_photos)

    3. **SpreadRepository**: Accepts SpreadDao.
       - `fun observeAllSpreads(): Flow<List<Spread>>` — all spreads
       - `suspend fun getSpreadById(id: Long): Spread?` — single lookup (not Flow — spreads are static)
       - `suspend fun insertAllSpreads(spreads: List<Spread>): Unit` — for pre-population

    4. **DeckRepository**: Accepts DeckDao.
       - `fun observeAllDecks(): Flow<List<Deck>>` — all decks
       - `fun observeBuiltInDecks(): Flow<List<Deck>>` — filter isCustom = false
       - `suspend fun createDeck(deck: Deck): Long`
       - `suspend fun updateDeck(deck: Deck): Unit`
       - `suspend fun deleteDeck(id: Long): Unit`

    Each repository:
    - Maps entities to domain models using the `.toDomain()` extensions from Plan 03
    - Maps domain models to entities using the `.toEntity()` extensions
    - Uses `distinctUntilChanged()` on Flow streams to prevent unnecessary recompositions
    - Uses `@Transaction` for multi-table operations (createReading, updateReading)
  </action>
