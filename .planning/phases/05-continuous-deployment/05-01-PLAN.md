<task type="auto">

  <action>
    Create `.github/workflows/release.yml` with a single job that:

    1. **Trigger**: `on: push: branches: [main]` (per D-86, D-87)
       - Add conditional skip if commit message contains `[skip release]` (per D-88)

    2. **Setup**: Reuse patterns from ci.yml — checkout, JDK 17, Android SDK, Gradle cache

    3. **Decode keystore** (per D-93):
       ```yaml
       - name: Decode keystore
         run: |
           echo "$RELEASE_KEYSTORE" | base64 -d > $RUNNER_TEMP/release.jks
           echo "RELEASE_KEYSTORE_PATH=$RUNNER_TEMP/release.jks" >> $GITHUB_ENV
         env:
           RELEASE_KEYSTORE: ${{ secrets.RELEASE_KEYSTORE }}
       ```

    4. **Version bump** (per D-82, D-83, D-84):
       Use a script step to:
       - Read current versionCode and versionName from build.gradle.kts
       - Increment versionCode by 1
       - Increment patch in versionName (semver: 1.0.0 → 1.0.1)
       - Set as environment variables for the build step
       - Do NOT commit back to repo (per D-84)
       
       ```bash
       CURRENT_CODE=$(grep 'versionCode' app/build.gradle.kts | grep -o '[0-9]\+')
       NEW_CODE=$((CURRENT_CODE + 1))
       
       CURRENT_NAME=$(grep 'versionName' app/build.gradle.kts | grep -o '"[^"]*"' | tr -d '"')
       # Increment patch: 1.0 → 1.0.0, 1.0.0 → 1.0.1
       if [[ "$CURRENT_NAME" =~ ^[0-9]+\.[0-9]+$ ]]; then
         NEW_NAME="${CURRENT_NAME}.0"
       elif [[ "$CURRENT_NAME" =~ ^[0-9]+\.[0-9]+\.[0-9]+$ ]]; then
         PATCH=$(echo "$CURRENT_NAME" | cut -d. -f3)
         NEW_NAME=$(echo "$CURRENT_NAME" | awk -F. -v OFS=. '{$3=$3+1; print}')
       else
         NEW_NAME="$CURRENT_NAME"
       fi
       
       echo "VERSION_CODE=$NEW_CODE" >> $GITHUB_ENV
       echo "VERSION_NAME=$NEW_NAME" >> $GITHUB_ENV
       echo "RELEASE_TAG=v${NEW_NAME}" >> $GITHUB_ENV
       ```

    5. **Build** (per D-99, D-104):
       ```yaml
       - name: Build Release APK
         run: ./gradlew :app:assembleRelease --no-daemon
         env:
           RELEASE_KEYSTORE_PASSWORD: ${{ secrets.RELEASE_KEYSTORE_PASSWORD }}
           RELEASE_KEY_ALIAS: ${{ secrets.RELEASE_KEY_ALIAS }}
           RELEASE_KEY_PASSWORD: ${{ secrets.RELEASE_KEY_PASSWORD }}
       ```

    6. **Create GitHub Release** (per D-89, D-90, D-91, D-96, D-98):
       Use `softprops/action-gh-release@v2` to:
       - Create tag from `v{versionName}` (per D-91)
       - Generate release notes from commits since last tag (per D-89, D-90)
       - Attach APK (renamed to `drawn-{versionName}.apk`) and `mapping.txt` (per D-96)
       
       For release notes, use `actions/github-script` to query commits since last release tag:
       ```yaml
       - name: Generate release notes
         id: notes
         uses: actions/github-script@v7
         with:
           script: |
             const { data: commits } = await github.rest.repos.compareCommits({
               owner: context.repo.owner,
               repo: context.repo.repo,
               base: context.payload.before || 'HEAD~1',
               head: context.sha
             });
             
             // Group by conventional commit type
             const grouped = { feat: [], fix: [], chore: [], other: [] };
             for (const commit of commits.commits) {
               const msg = commit.commit.message.split('\n')[0];
               if (msg.startsWith('feat:')) grouped.feat.push(msg);
               else if (msg.startsWith('fix:')) grouped.fix.push(msg);
               else if (msg.startsWith('chore:')) grouped.chore.push(msg);
               else grouped.other.push(msg);
             }
             
             let notes = '## Changes\n\n';
             if (grouped.feat.length) notes += '### Features\n' + grouped.feat.map(c => `- ${c}`).join('\n') + '\n\n';
             if (grouped.fix.length) notes += '### Fixes\n' + grouped.fix.map(c => `- ${c}`).join('\n') + '\n\n';
             if (grouped.other.length) notes += '### Other\n' + grouped.other.map(c => `- ${c}`).join('\n') + '\n';
             
             return notes;
           result-encoding: string

       - name: Create GitHub Release
         uses: softprops/action-gh-release@v2
         with:
           tag_name: ${{ env.RELEASE_TAG }}
           name: Release ${{ env.VERSION_NAME }}
           body: ${{ steps.notes.outputs.result }}
           files: |
             app/build/outputs/apk/release/drawn-${{ env.VERSION_NAME }}.apk
             app/build/outputs/mapping/release/mapping.txt
         env:
           GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
       ```

    Key decisions to honor:

    - D-98: GitHub Release with tag, notes, artifacts
    - D-103: Separate from existing CI workflow
    - D-104: Reuses same Gradle commands with release signing
    - D-105: No app code changes
  </action>
