## Navigation Structure

3 bottom navigation tabs:

| Tab | Icon | Route | Screen |
|-----|------|------|--------|
| Readings | AutoStories | readings | ReadingListScreen |
| Decks | Style | decks | DeckListScreen |
| Settings | Settings | settings | SettingsScreen |

Each tab maintains its own navigation stack:
- Readings: List → Detail, List → Add
- Decks: List → Detail (with integrated cards)
- Settings: Single screen (links to backup in Phase 12)

---

## Screen Specifications

### Bottom Navigation Bar
- Height: 80dp (Material 3 standard)
- Background: DarkSurface (#1E1E1E)
- 3 items with icons and labels
- Selected indicator: Gold underline or tinted icon

### Deck List Screen
- LazyColumn with deck items
- Each item: name, description (truncated), card count badge
- FAB: Add new deck
- Tap: Navigate to DeckDetailScreen
- Long press / context menu: Edit, Delete

### Deck Detail Screen
- Header: Deck name, description, edit button
- Cards section: LazyGrid (2 columns) with card thumbnails
- Card item: image thumbnail, name, keywords preview
- FAB: Add new card
- Tap card: Edit card dialog

### Tag Management
- Tag list: Chips with color background
- Add button: Opens create dialog
- Tap chip: Edit dialog
- Long press: Delete option

### Reading Tag Assignment (in Reading Detail)
- Assigned tags: Row of colored chips with X dismiss
- Add button: Opens tag picker bottom sheet
- Tag picker: FilterChip selection list

### Tag Filter Sheet (Reading List)
- Modal bottom sheet
- Tag filter chips (multi-select)
- "Favorites only" toggle
- Apply / Clear buttons

### Settings Screen
- List with SettingsTile items:
  - App version (display, non-interactive)
  - Backup & Restore (navigation link to Phase 12)
