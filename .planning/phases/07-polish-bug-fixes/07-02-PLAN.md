  <action>
The current implementation uses NavDisplay with a manual back stack, which doesn't natively support the SharedTransitionScope API from Navigation Compose 3.

Implement animatedContent transitions that create a "card expansion" feel:

1. Add animatedContent to the NavDisplay entry transitions
2. Define a custom transition that scales the entering content from the center
3. For list→detail: fade in with slight scale up (0.95 → 1.0) to simulate the card "opening up"
4. For detail→list: fade out with slight scale down (1.0 → 0.95)

This achieves the "continuity between list and detail" goal from D-01 without requiring migration to NavHost. The visual effect mimics shared element expansion.

Alternative (if time permits): Investigate whether Navigation 3's SharedTransitionScope can be used with NavDisplay - if so, implement proper shared elements.
