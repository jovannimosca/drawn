    The composable should:
    - Accept `modifier: Modifier = Modifier`
    - Fill the available space with `Modifier.fillMaxSize()`
    - Draw a dark purple-to-black radial gradient as the base (from `DarkBackground` 0xFF121212 to slightly darker at edges)

    - Draw ~40-60 small white/very-light stars as tiny circles (radius 0.5-1.5dp) at random-ish positions using `drawCircle`
    - Stars should use alpha between 0.15 and 0.4 for subtlety
    - Use a fixed seed for star positions so they don't redraw differently on each recomposition — use `remember` with a predefined list of `Offset` and `Float` pairs

    - `androidx.compose.ui.geometry.Offset`
    - `androidx.compose.ui.graphics.Brush`
    - `androidx.compose.ui.graphics.Color`
    - `androidx.compose.ui.graphics.drawscope.DrawScope`

    The star positions should be generated once using `remember` with a deterministic seed (e.g., a hardcoded list of 50 star positions with x%, y%, radius, and alpha values). This ensures consistency across recompositions.
