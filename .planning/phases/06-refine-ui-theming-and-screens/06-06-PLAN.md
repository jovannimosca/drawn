    - Cards sorted by positionOrder

    **CrossAndStaffLayout (Celtic Cross):**
    - Uses a Box-based layout with two areas:
      - Left side: Cross shape (6 cards)
      - Right side: Staff column (4 cards)
    - Cross arrangement using nested Rows and Columns:
      ```
      Row {
        Column (Cross) {
          Row { Position 5 (above) }
          Row { Position 4 (left) + Position 1 (center) + Position 6 (right) }
          Row { Position 3 (below) }
          // Position 2 overlays Position 1 (crossing card)
        }
        Spacer(24.dp)
        Column (Staff) {
          Position 7
          Position 8
          Position 9
          Position 10
        }
      }
      ```
    - Position 2 (crossing) should be rendered slightly offset/rotated over Position 1 — use a Box with both cards, Position 2 rotated 90° and slightly offset
    - Each card uses the `cardContent` lambda for rendering (reuses ReadingDetailCardItem)
    - Cards sorted by positionOrder before layout

    **FallbackGridLayout:**
    - Same as current 3-column chunked grid
    - Used for any unrecognized spread name
