    Replace the current `when(state.currentStep)` step switching with `HorizontalPager`:

    1. Add imports:
       - `import androidx.compose.foundation.pager.HorizontalPager`
       - `import androidx.compose.foundation.pager.rememberPagerState`

    2. Create a `PagerState` synced with wizard state:
       ```kotlin
       val steps = AddReadingStep.entries
       val pagerState = rememberPagerState(
           initialPage = state.currentStep.ordinal,
           pageCount = { steps.size }
       )
       ```

    3. Replace the `when(state.currentStep)` block (lines 91-127) with:
       ```kotlin
       HorizontalPager(
           state = pagerState,
           userScrollEnabled = true,
           modifier = Modifier
               .fillMaxWidth()
               .weight(1f)
       ) { page ->
           val step = steps[page]
           when (step) {
               AddReadingStep.SpreadPicker -> {
                   SpreadPickerStep(
                       spreads = state.spreads,
                       selectedSpread = state.selectedSpread,
                       onSpreadSelected = { viewModel.selectSpread(it) }
                   )
               }
               AddReadingStep.CardAssignment -> {
                   state.selectedSpread?.let { spread ->
                       CardAssignmentStep(
                           spread = spread,
                           assignedCards = state.assignedCards,
                           onPositionCardSelected = { pos, card -> viewModel.assignCard(pos, card) },
                           reversedPositions = state.reversedPositions,
                           onToggleReversed = { viewModel.togglePositionReversed(it) }
                       )
                   }
               }
               AddReadingStep.NotesAndSave -> {
                   NotesAndSaveStep(
                       title = state.title,
                       notes = state.notes,
                       photoUris = state.photoUris,
                       isSaving = false,
                       onTitleChange = { viewModel.updateTitle(it) },
                       onNotesChange = { viewModel.updateNotes(it) },
                       onAddPhoto = { viewModel.addPhoto(it) },
                       onRemovePhoto = { viewModel.removePhoto(it) },
                       onSave = { viewModel.saveReading() }
                   )
               }
           }
       }
       ```

    4. Sync pager with button navigation — update WizardBottomBar to use pagerState:
       - When Next button clicked: `viewModel.goToNextStep()` AND `coroutineScope.launch { pagerState.animateScrollToPage(pagerState.currentPage + 1) }`
       - When Back button clicked: `viewModel.goToPreviousStep()` AND `coroutineScope.launch { pagerState.animateScrollToPage(pagerState.currentPage - 1) }`
       - Need to add `import androidx.compose.runtime.rememberCoroutineScope` and `import kotlinx.coroutines.launch`

    5. Sync swipe with step indicator — add `LaunchedEffect(pagerState.currentPage)` to update the WizardStepIndicator when user swipes. However, since AddReadingStep is managed by ViewModel, we need to either:
       - Option A: Have the ViewModel track a `currentPage` field that the pager updates on page change
       - Option B: Keep the WizardStepIndicator using state.currentStep and have the pager's onPageChanged callback call a ViewModel method to sync

       Use Option A: Add `fun setPage(page: Int)` to ViewModel that maps page ordinal to AddReadingStep and updates currentStep. Call this from `pagerState`'s `snapshotFlow` or `LaunchedEffect`.

    6. Remove the `Spacer(modifier = Modifier.height(24.dp))` between WizardStepIndicator and step content — the pager provides natural spacing.

    7. Keep the WizardBottomBar unchanged — it still provides Back/Next buttons for accessibility.
