<objective>
Integrate gradle-semantic-release-plugin to sync version between semantic-release and Android APK

Purpose: Currently semantic-release determines version but Android APK version is hardcoded in build.gradle.kts. This integration ensures the APK versionName matches the GitHub release tag automatically.

Output: Version synchronization pipeline where semantic-release → gradle-semantic-release-plugin → gradle.properties → Android build
</objective>

<context>
@app/build.gradle.kts
@gradle.properties
@.github/workflows/release.yml
</context>

<tasks>

<task type="auto">
  <name>Task 1: Move version to gradle.properties and update build.gradle.kts</name>
  <files>gradle.properties, app/build.gradle.kts</files>
  <action>
1. Add to gradle.properties: `version=1.0.0`
2. In app/build.gradle.kts, change:
   - `versionCode = 1` → `versionCode = project.property("versionCode").toInt()`
   - `versionName = "1.0"` → `versionName = project.property("version") as String`
3. Add to gradle.properties: `versionCode=1`
</action>
  <verify>grep -E "version=|versionCode=" gradle.properties && grep "project.property" app/build.gradle.kts</verify>
  <done>Version defined in gradle.properties, Android build reads from properties</done>
</task>

<task type="auto">
  <name>Task 3: Update release.yml to install dependencies and use plugin</name>
  <files>.github/workflows/release.yml</files>
  <action>
1. After checkout, add: `npm install`
2. Replace semantic-release-action step with:
   - Uses semantic-release directly: `npx semantic-release`
   - The gradle-semantic-release-plugin will run `./gradlew` to bump version in gradle.properties
3. After semantic-release completes, read version from gradle.properties:
   ```yaml
   - name: Read version from gradle.properties
     run: echo "VERSION_NAME=$(grep '^version=' gradle.properties | cut -d= -f2)" >> $GITHUB_ENV
   ```
4. Continue with existing APK build (now uses synchronized version)
</action>
